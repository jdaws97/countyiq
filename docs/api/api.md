# API

## API Architecture

FastAPI running under Uvicorn in a Docker container (`countyiq-api`). Caddy reverse proxies `/api/*` to the container on port 8000. All services share a Docker network (`countyiq`); Postgres is accessible at `postgres:5432` (Docker DNS). No VPC constraints — the API can reach any external service directly (OpenRouter for LLM search, webhook URLs, etc.).

```
Internet → Cloudflare → Caddy (:443) → reverse_proxy → api:8000 (FastAPI/Uvicorn)
                                                              ↓
                                                        postgres:5432
```

## API Endpoints

| Endpoint | Method | Purpose | Example |
|---|---|---|---|
| `/api/parcels/bbox` | GET | Parcels within a map bounding box | `?west=-76.8&south=39.8&east=-76.6&north=40.0&layer=delinquent` |
| `/api/parcels/{pidn}` | GET | Property report card (full details + computed fields) | `/api/parcels/4300006006500` |

| `/api/parcels/{pidn}/adjacent` | GET | Neighboring parcel owners (for assemblage) | `/api/parcels/4300006006500/adjacent` |
| `/api/owners/top` | GET | Ownership concentration leaderboard | `?by=parcel_count&municipality=Conewago&limit=50` |
| `/api/owners/{owner_id}` | GET | Owner profile with all properties | `/api/owners/12345` |
| `/api/search` | GET | Fuzzy search across owners, addresses, parcels | `?q=smith+main+st&municipality=Conewago` |
| `/api/changes` | GET | Recent data changes across all sources | `?since=7d&type=ownership_transfer,new_delinquency` |
| `/api/municipalities` | GET | List all municipalities with summary stats | -- |
| `/api/municipalities/{name}` | GET | Municipality profile data | `/api/municipalities/conewago-twp` |
| `/api/stats` | GET | Homepage stats (total parcels, changes this week, total assessed) | -- |
| `/api/ops/health` | GET | System health dashboard data | See `docs/operations/health-dashboard.md` |

## Vector Tiles

Tiles are **not served by the API**. They are pre-generated by the Dagster tile pipeline, uploaded to Cloudflare R2, and served via Cloudflare CDN at `/tiles/{layer}/{z}/{x}/{y}.pbf` (7-day cache). The API has no tile routes. See `docs/frontend/architecture.md` for the tile generation pipeline.

## FastAPI App

`api/main.py` — same router structure, same CORS middleware, same health endpoint. No Mangum wrapper, no `handler.py`. Uvicorn serves the app directly.

```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from routes import parcels, owners, search, changes, municipalities, stats, ops

app = FastAPI(
    title="CountyIQ API",
    version="0.1.0",
)

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # Lock down to Cloudflare Pages domain in production
    allow_methods=["GET"],
    allow_headers=["*"],
)

# All routes use /api/* prefix. Caddy reverse proxies /api/* to this container.
# Tiles are NOT served by the API — they're in Cloudflare R2, served via CDN.
app.include_router(parcels.router, prefix="/api/parcels", tags=["parcels"])
app.include_router(owners.router, prefix="/api/owners", tags=["owners"])
app.include_router(search.router, prefix="/api/search", tags=["search"])
app.include_router(changes.router, prefix="/api/changes", tags=["changes"])
app.include_router(municipalities.router, prefix="/api/municipalities", tags=["municipalities"])
app.include_router(stats.router, prefix="/api/stats", tags=["stats"])
app.include_router(ops.router, prefix="/api/ops", tags=["ops"])

@app.get("/api/health")
def health():
    return {"status": "ok"}
```

No `handler.py` needed. No Mangum. The app is served directly by Uvicorn inside the Docker container.

## Caddy Routing

Caddy is the only public entry point on the VPS. It handles TLS termination (auto-provisioned via Let's Encrypt) and reverse proxies API requests to the FastAPI container. No CloudFront, no API Gateway, no origin-verify header needed.

```
{$DOMAIN} {
    handle /api/* {
        reverse_proxy api:8000
    }
    # Frontend served by Cloudflare Pages (separate domain/subdomain)
    # Tiles served by Cloudflare R2 via CDN (separate URL)
}
```

Since the frontend is on Cloudflare Pages (different origin), CORS middleware in FastAPI handles cross-origin requests. Cloudflare proxies traffic to the VPS (SSL mode: Full Strict), so Caddy's Let's Encrypt cert is validated end-to-end.

## Connection Pooling

Simpler than Lambda. Uvicorn workers maintain persistent connections to Postgres over the Docker network (localhost-equivalent latency). No cold start concern — connections stay open as long as the worker lives. No reserved concurrency cap needed.

```python
# api/lib/database.py
import os
import psycopg2

_conn = None

def get_connection():
    global _conn
    if _conn is None or _conn.closed:
        _conn = psycopg2.connect(
            host=os.environ["DATABASE_HOST"],
            port=os.environ.get("DATABASE_PORT", "5432"),
            dbname=os.environ["DATABASE_NAME"],
            user=os.environ["DATABASE_USER"],
            password=os.environ["DATABASE_PASSWORD"],
            connect_timeout=5,
        )
        _conn.autocommit = True  # Read-only API — no transactions needed
    return _conn
```

Postgres `max_connections` is ~100 (Docker default). Connection budget:

| Consumer | Max Connections | Notes |
|---|---|---|
| API (Uvicorn workers) | ~4 | 2 workers, each may hold 1-2 connections |
| Dagster (webserver + daemon) | 5-8 | Varies during pipeline runs |
| Dagster sensors | 2-3 | Infra metrics + pipeline status |
| Alembic migrations | 1 | Only during deploys |
| psql via SSH | 1-2 | Development/debugging |
| **Total** | **~15** | Well under 100 limit |

No RDS Proxy, no concurrency cap, no connection budget anxiety. All services are on the same Docker network with sub-millisecond latency to Postgres.

## Deployment

Push to `main` triggers the full pipeline:

1. **GH Actions** builds Docker image for the API
2. **GH Actions** pushes image to GHCR (`ghcr.io/jdaws/countyiq-api:latest`)
3. **Watchtower** on VPS detects new image (polls every 5 min)
4. **Watchtower** pulls new image and restarts the `countyiq-api` container
5. **Docker healthcheck** confirms the new container is healthy

No Lambda zip packaging. No `aws lambda update-function-code`. No CloudFront invalidation.

**Rollback:** Pull and restart with a specific image tag:

```bash
# On VPS
docker compose pull api
docker compose up -d api

# Or pin to a specific SHA
docker compose -f docker-compose.yml up -d api  # after editing image tag in compose file
```
