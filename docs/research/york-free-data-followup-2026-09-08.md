Research date: September 8, 2026. This is a compact, read-only addition to the existing York research and dataset register. It promotes only records reached on official publisher pages or documents. Free means no account or payment was encountered for viewing; it does not grant automated collection, bulk reuse, or completeness.

The subsequent [value test against CountyIQ's local snapshot](york-free-data-value-test-2026-09-08.md) found useful additions and matching limits: Carvana's YCCD address differs from the township agenda, Red Land's exact phase is unresolved, and Joseph Machine's announcement describes a different scope from the planning row. Preserve those differences before attaching records to existing projects.

## Bounded gaps

The public RACP application-search interface was verified, but a named York row could not be extracted from its dynamic results in this pass. The official Joseph Machine announcement is enough to record a specific RACP award event, while preserving that distinction. The YCCD PDF is the strongest second permit-family addition because it supplies current project and permit details outside Springettsbury; it is not a permit-history or construction-start feed. York Suburban’s agenda supplies detailed bid evidence but requires a later official decision record to establish award status.

## Practical acquisition order

1. Capture YCCD’s weekly status PDF as a dated, low-volume review-event source, preserving each row and document snapshot. Match to existing parcels and planning records only after address normalization.
2. Add a RACP award-event workflow keyed by beneficiary, project name, award date, and amount. Search the public e-RACP interface only for targeted known entities/projects; do not rely on a press release for payment or construction status.
3. Monitor York Suburban agendas and minutes for the high-school project and similar construction actions. Promote an agenda bid to an award only when a later official action records approval/execution.

These sources should remain separate event families: funding award, environmental/earth-disturbance review, and public procurement. None establishes beneficial ownership, utility capacity, an actual construction start, or completion.
