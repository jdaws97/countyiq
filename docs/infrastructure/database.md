# RDS PostgreSQL / PostGIS

## RDS PostgreSQL / PostGIS

### Instance Configuration

| Setting | Value |
|---|---|
| Engine | PostgreSQL 16 |
| Instance class | `db.t3.micro` (2 vCPU burstable, 1 GB RAM) |
| Storage | 20 GB gp3 (free tier covers 20 GB) |
| Multi-AZ | No (single AZ — cost savings, acceptable for solo dev) |
| Database name | `countyiq` |
| Port | 5432 |
| Public access | **No** (default VPC subnets, no public IP assigned to RDS; accessible from EC2 within same VPC) |
| Extensions required | `postgis`, `postgis_topology`, `pg_trgm` (fuzzy text matching for entity resolution) |
| Encryption | At rest (default AWS-managed key) |

### Free Tier Details

- **750 hours/month of db.t3.micro** for 12 months (enough to run 24/7 for a full year)
- **20 GB of General Purpose (gp3) storage** included
- **20 GB of backup storage** included (automated backups)
- After free tier: ~$12–15/month for db.t3.micro with 20 GB gp3

### Connection from EC2

The EC2 instance connects to RDS over the **default VPC network** (not the public internet). Both resources sit in the same default VPC. The connection uses the RDS endpoint hostname on port 5432. RDS has no public IP assigned (security enforced by lack of IP, not by subnet type).

**Security:** The RDS security group allows inbound on port 5432 **only from the EC2 security group**. No other access is permitted. Security group rules prevent inbound connections from the internet, making the database completely inaccessible from outside the VPC.

**Credential storage:** The RDS master password is auto-generated by Terraform's `random_password` resource at apply time and stored in AWS Systems Manager Parameter Store (SecureString) at `/countyiq/rds-password`. The EC2 instance retrieves it at boot time via the IAM instance profile. Lambda receives it as a Terraform-set encrypted environment variable. The full connection string is assembled from Parameter Store values — never hardcoded or committed to git.

**Parameter Store values:**

| Parameter Path | Type | Value |
|---|---|---|
| `/countyiq/rds-host` | String | RDS endpoint (output from Terraform) |
| `/countyiq/rds-password` | SecureString | Master password |
| `/countyiq/rds-dbname` | String | `countyiq` |
| `/countyiq/rds-username` | String | `dagster_admin` |

### Local Development Access

To connect to RDS from your local machine (e.g., for running queries in pgAdmin or DBeaver), use Session Manager port forwarding through the EC2 instance:

```bash
# Forward local port 5433 to RDS through the EC2 instance
aws ssm start-session \
  --target <instance-id> \
  --document-name AWS-StartPortForwardingSessionToRemoteHost \
  --parameters '{"host":["<rds-endpoint>"],"portNumber":["5432"],"localPortNumber":["5433"]}'

# Then connect your SQL client to:
# Host: localhost
# Port: 5433
# Database: countyiq
# User: dagster_admin
```
