**Subject:** Request for Bulk Distribution of Electronic Case Records — York County

To the Administrative Office of Pennsylvania Courts, Information Technology Division:

I am requesting bulk distribution of electronic case records pursuant to 204 Pa. Code § 213.81 for the following:

**Data Requested:**

1. **CPCMS (Common Pleas Case Management System) dockets for York County** — civil and criminal case index data including:
   - Case number and caption
   - Filing date
   - Case type and status
   - Party names (plaintiff/defendant)
   - Parcel number (where recorded — CPCMS has a parcel search field)
   - Disposition and date
   - Judgment amounts (where applicable)

2. **MDJS (Magisterial District Judge System) dockets for York County** — including:
   - Case number
   - Filing date
   - Case type (landlord-tenant, civil, criminal)
   - Party names
   - Property address (where applicable, particularly landlord-tenant cases)
   - Disposition

**Date range:** Records from January 1, 2020 to present.

**Preferred format:** CSV, delimited text, or database export. Any standard electronic format is acceptable.

**Purpose and Use:**

This data will be used for a civic intelligence platform (CountyIQ) that aggregates publicly available property and civic data for York County, PA. The platform is designed for public information purposes — property research, ownership analysis, and civic transparency for county staff, title companies, journalists, and residents.

The data will be:
- Stored securely in an encrypted database
- Displayed only in aggregate or in the context of public property records
- Not used for marketing, solicitation, or commercial resale of raw data
- Subject to all AOPC data use restrictions

**Security plan:** Data will be stored in an AWS RDS PostgreSQL database with encryption at rest (AES-256), accessible only via authenticated API with role-based access controls. Person-level data will require user authentication before display. Query audit logging will be enabled for all person-level lookups.
